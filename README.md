# Bare Metal Study Notes

This repository is my public CSAPP study log for learning bare-metal and low-level systems programming. The goal is to keep the notes, code, and chapter structure clean enough that anyone can navigate the material without noise.

## What this repo contains

- Chapter-based study notes for CSAPP
- Theory in Markdown, code in `.c`, and occasional assembly references in `.s`
- One folder per chapter, with one folder per section

## How it is organized

- `chapters/` — main chapter directory
- `chapters/<chapter>/README.md` — chapter index with direct links
- `chapters/<chapter>/sections/<section>/theory.md` — section theory
- `chapters/<chapter>/sections/<section>/section.c` — section code, when needed
